# Solutions are published on the learner-facing site

Each page carries a click-to-open solution reveal containing both a live solution demo and its full source code. We chose this over withholding solutions or linking an external repo because the learner works alone and must be able to unblock themselves; the goal demo is visible from the start, so the reveal is a fallback rather than the first move. Consequence: every page ships runnable solution code, so the page content model must define how the goal demo and the solution are stored and kept in sync.

Considered options: no published solution; a solution repository or gist linked off-site; hints only.
