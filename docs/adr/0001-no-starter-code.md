# No starter code for the exercises

Every exercise is stated as a goal plus self-checkable acceptance criteria; the learner writes the whole page themselves, including the store. Shipping a scaffold per page would silently make the decisions the workshop exists to teach — store shape, where actions live, how finely to select — and deleting starter code is a far weaker exercise than writing it from nothing. Consequence: a page must state the expected end result precisely enough to build from an empty project.

Considered options: a starter repo per page; copy-paste code blocks to adapt; "fill in the blank" TODOs in a given file.
