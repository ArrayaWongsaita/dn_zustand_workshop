# Learners never clone this repository

The workshop is delivered as a website that learners view; they scaffold their own Vite + React project and write their own code, and they never see this repository's source. We chose this over a cloneable workshop repo because the teaching copy, goal demos, and reveals live on the site, and a repo would expose the site's routing and build plumbing — material the ladder deliberately never teaches. Consequence: everything learner-facing must be self-contained on a page, and this repository's README, docs, and issues are written for the build session only.

Considered options: a cloneable repo with a branch per page; a downloadable archive per exercise.
